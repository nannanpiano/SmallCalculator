# SmallCalculator

用 Python 从零手写的命令行计算器。程序启动后，每输入一行算式，就打印出计算结果，直到输入 `quit` 退出。

这是一个工程能力练习：求值算法本身不难，重点在算法外面的部分，也就是循环读取输入、切分记号、处理错误、保存状态、读写文件，以及把一个模糊的目标拆成几个能配合工作的小块。

## 运行

需要 Python 3.10 或更高版本，不依赖任何第三方库。

```bash
python3 core.py
```

## 功能

| 功能 | 示例输入 | 输出 |
|---|---|---|
| 四则运算，先乘除后加减 | `2+3*4` | `14` |
| 从左往右计算 | `10 - 2 - 3` | `5` |
| 小数 | `3+ 4.5*2` | `12.0` |
| 括号（可嵌套） | `2*(3+(4-1))` | `12` |
| 变量赋值 | `x = 3` | `x = 3` |
| 使用变量 | `x * 2` | `6` |
| 查看历史记录 | `history` | 之前的算式和结果 |
| 退出 | `quit` | |

### 错误处理

输入有误时只打印提示，程序会继续等待下一行输入，不会退出：

| 输入 | 提示 |
|---|---|
| `5 / 0` | 除数不能为零 |
| `(2+3` | 括号不配对：缺少右括号 |
| `2+3)` | 括号不配对：多了右括号 |
| `3 $ 4` | 非法字符：$ |
| `3 +` | 算式不完整 |
| `* 2` | 运算符 * 前面缺少数字 |
| `y + 1`（y 未赋值） | 变量未定义：y |
| `3 = 4` | 变量名不合法 |
| 直接按回车 | 输入为空 |

### 历史记录

每次计算成功，输入和结果都会追加写入 `log.txt`，关掉程序再打开仍然保留。出错的输入不会被记录。

## 代码结构

所有代码都在 `core.py` 中，一行输入的处理流程是：

```
输入字符串
  → tokenize           切成记号列表，如 "2*(x+1)" → [2, '*', '(', 'x', '+', 1, ')']
  → check_syntax       检查语法：括号是否配对、数字和运算符是否交替出现
  → replace_variables  把变量名替换成它的值
  → calculator_with_buffer  用栈找到最里层的括号，交给 calculator 计算后替换，直到没有括号
  → calculator         计算不含括号的算式：先算乘除，再从左往右算加减
  → 结果
```

- `run`：主循环（REPL），负责读取输入、识别 `quit` 和 `history` 命令、打印结果、写入历史记录
- `evaluate`：把一个算式字符串算成一个数，普通计算和赋值语句的右边共用它
- `assign`：处理 `name = 算式` 形式的赋值
- `CalcError`：表示"用户输入有误"的异常，由发现错误的函数抛出，在 `run` 中统一接住

## 已知限制

- 不支持负数，比如 `-3 + 2`、`2 * -1` 会提示语法错误
- 按 `Ctrl+C` 或 `Ctrl+D` 退出时，会打印一段 Traceback
- 变量只在单次运行中有效，重启程序后需要重新赋值
- `log.txt` 写在运行程序时终端所在的目录，而不是 `core.py` 所在的目录
- 赋值语句的历史记录格式是 `x = 3 = 3`

## 开发过程

项目按 7 个版本逐步完成，每个版本都可以独立运行，并对应一次 git 提交：

| 版本 | 内容 |
|---|---|
| 0 | 复读循环：原样输出输入的内容，搭好 REPL 骨架 |
| 1 | 计算两个数的四则运算 |
| 2 | 切分记号，支持任意长度的算式和运算优先级 |
| 3 | 支持括号 |
| 4 | 错误处理：任何输入都不会让程序崩溃 |
| 5 | 支持变量 |
| 6 | 历史记录写入文件，实现持久化 |

运行 `git log --oneline` 可以查看每个版本的提交。
